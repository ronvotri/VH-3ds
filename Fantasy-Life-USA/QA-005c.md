# QA tĩnh — CP005c, kết thúc CP005

| Kiểm tra | Kết quả |
|---|---|
| Gói mới | 0042–0045 (4 × 100) |
| Câu mới CP005c | **400** |
| CP005a + 005b + 005c | **700 + 900 + 400 = 2.000** |
| Tổng tích lũy | **4.500 / 34.812 (12,93%)** |
| Câu nguồn còn lại | **30.312** |
| ID hợp lệ trên nguồn | **4.500/4.500** |
| Trùng ID | **0** |
| Thiếu bản dịch | **0** |
| Mismatch token `{CTRL:hex}` | **0** |
| Unicode không NFC | **0** |
| Câu CP005c vượt ngưỡng dài thô | **0** |
| SHA-256 CP005c mới | `052ed3544734b7b358d86a655298e0e5d7cd238688d3c2bfe4ffce8fe456f738` |
| Font/độ rộng/ngắt trang trên 3DS | **CHƯA KIỂM** |
| Quan hệ và speaker NPC trong cảnh | **CẦN QA** |
| Patch/CIA có thể chơi | **CHƯA CÓ** |

**Lưu ý:** Bộ lọc số thô có cảnh báo giả với số nằm cạnh control token, ví dụ `4 ME` của EN_B nghĩa là `for me`, và dạng viết số bằng chữ của EN_A. Các lượng vật phẩm, Dosh và điểm có trong bảng dịch cần thử trên UI thật.

**Sửa đã thực hiện:** gói 0043 mục 44 và 50, đổi tiền tố xưng hô hai giới thành cấu trúc chung `Này, chàng trai/cô gái trẻ ơi...` để tránh hiển thị `Chàng cô gái`.
